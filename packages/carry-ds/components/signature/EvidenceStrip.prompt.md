Mono key/value rows for the second read — sources, certainty, gates — each optionally carrying a StateMark.
```jsx
<EvidenceStrip items={[
  {label:'cycle time', value:'3–5 days → about 1 day', certainty:'provisional', source:'self-reported, BA function'},
  {label:'team scale', value:'held', certainty:'provisional', gated:{gate:'verification', owner:'S. Asif'}},
  {label:'measured adoption', value:'not yet', certainty:'unknown'},
]} />
```
Use where trust depends on provenance; not on every sentence.
