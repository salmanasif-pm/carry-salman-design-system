The Carry signature: a 2px ink rule with one ochre tick. The tick's form says what the line is doing.
```jsx
<Threshold />                    // decision point (default)
<Threshold fn="evidence" />      // claim above, support below — outline tick
<Threshold fn="progression" />   // tick at the end: movement
<Threshold fn="transition" />    // tick centred: section change
<Threshold fn="reflection" />    // small tick: personal / learning
<Threshold fn="separation" />    // no tick: plain divider
<Threshold orientation="vertical" />
```
One threshold per view. Never two colours, never decorated.
