Mono source-ancestry block: sources, version, what it supersedes, what changed. Where trust depends on it, the source travels with the output.
```jsx
<Provenance sources={['claims register (internal)','role record (internal)']} version="v1" date="2026-09-11" changed="figures removed; approved wording only" maxLines={2}/>
```
maxLines by mode: Social 1, Executive 2, Systems/Evidence unlimited. Restricted sources are named as restricted, never linked.
