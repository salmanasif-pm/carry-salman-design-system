# Decision trace

One file per consequential decision, `NNNN-slug.md`, never deleted. States: **Locked** (identity layer; reopens only with new evidence, a changed constraint or Salman's explicit decision) · **Locked on identity approval** (locks automatically when Salman approves the identity; until then Open) · **Open** (grammar layer, v0.x) · **Superseded** (kept as history; names its successor).

Each entry records: decision · options considered · trade-off · evidence and ancestry · risks · what would reopen it · owner · date · affected modes and components. Governance: `docs/governance.md`. Token values and component semantics change only through an entry here (`CLAUDE.md`).
