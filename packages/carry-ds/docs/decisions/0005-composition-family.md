# 0005 — The composition family: seven forms, one line

**State:** Open (grammar layer) · **Owner:** Salman Asif · **Date:** 2026-09-11 (v0.9.1) · **Affects:** `Composition`, `HandleTruth`, `Threshold`; content schema `form`; every template

**Decision.** Every artifact expresses one relationship between a first read above the threshold and an exact second read below it. Seven forms: handle / what's actually going on · claim / support · outcome / how it was enabled · question / conditions · direction / consequence · intention / reflection · observation / development. Each form fixes its default labels, tick function and lead prefix (Decision underneath · So · Next · Open · Recommendation · Kept · Still forming). Handle/truth is the sharpest form, not the only one. Every form except observation-development requires a lead line.

**Options considered.** Handle/Operating Truth as the single story (v0.9; superseded because every artifact became a corrective reveal and the system announced its own methodology). Free-form labels per artifact (rejected: the tick and labels are how a reader learns the grammar; they must be stable).

**Trade-off.** Seven forms are more to learn than one; the labels carry the teaching. Adding an eighth form is a decision, not a prop.

**Evidence and ancestry.** Brief v1.2 §4 doctrine and §9 candidate components; `docs/delta-report-v0.9.1.md` §1 "Storytelling"; `guidelines/brand-compositions.html`.

**Risks.** Authors may pick handle-truth by habit; templates ship with the form that fits their content kind. Public copy uses the plain labels (`docs/rules.md` public language).

**Reopens if.** A recurring artifact cannot be expressed in the seven; a form is never used after the first measurement review.
