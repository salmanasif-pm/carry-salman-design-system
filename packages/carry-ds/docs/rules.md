# Rule hierarchy — v0.9.1

Absolute aesthetic laws from v0.9 are reclassified into three tiers. Exceptions must be reasoned and recorded (`docs/exceptions/`), never decorative.

## Invariants — strict, no exceptions
1. No invented or overstated evidence. Templates ship neutral placeholders (`[bracketed]`) or content labelled *illustrative example — not Salman evidence*; verified Salman content uses Claims Register wording only.
2. Unknown stays Unknown.
3. No colour-only meaning. Certainty is fill; gate is a bar; release is text.
4. Confidentiality and release permission are preserved; release approval ≠ factual confirmation.
5. Provenance travels wherever trust depends on it.
6. Accessibility is not optional (`docs/accessibility.md`).
7. Public artifacts never silently contain operating-only information (`superseded`, `internal`, `restricted` fail a public build).
8. One canonical meaning layer feeds every renderer.

## Strong defaults — normal expression; documented exceptions allowed
- One restrained signal hue (ochre).
- Medium (500) headline weight, not bold.
- Square geometry; 2px radius only on controls.
- No gradients.
- Minimal shadows (one, for floating UI).
- Limited card use — rules and space before frames.
- One principal visual signature (the threshold); one per view.
- Decision-oriented structure: a closing line (decision, next, open question, kept) on every artifact meant to be acted on. `observation-development` may omit it — that is the form's point.

## Mode-dependent choices — controlled variation that serves the reader
- Professional photography in portfolio, biography or consulting introductions (`executive-deck` has an optional portrait slot).
- Stronger typographic emphasis (600) where hierarchy needs it inside body text.
- A framed module when grouping genuinely improves comprehension (`BoundaryFrame` is one).
- A serif — only if a future editorial test shows it materially improves long-form reading. Not adopted.
- Warmer, more upbeat language in personal and social modes; contractions and the occasional question mark are natural voice, not violations.
- Punctuation appropriate to the voice. Exclamation marks remain unusual, not banned.

## Public language
Keep *operating truth*, *provenance*, *governed momentum*, *next responsible decision*, *operational custody* as internal concepts (docs, schemas, governance). In public copy prefer: *what's actually going on* · *where this comes from* · *moving without losing the plot* · *what we decide next* · *who actually holds it*. Use the internal term publicly only when it reads naturally. The north star — *make complexity legible enough for the next responsible decision* — is a strategy statement, not recurring copy.
